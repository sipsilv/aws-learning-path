Upload the file to ur bucket

aws s3 cp .\example.txt s3://silv-bucker-720561061087-ap-south-2-an/example.txt

Create a bucket in a region with the name

aws s3api create-bucket --bucket second-bucket-example-for-silv --region us-east-1

Query for a specific bucket

aws s3api list-buckets --query "Buckets[?Name =='second-bucket-example-for-silv']"

Delete a bucket

aws s3api delete-bucket --bucket second-bucket-example-for-silv
